# The One-Line Laugh

> My password manager remembers every password I've ever had except the one I need right now, which is the only job it has.

## Run

Run `python3 main.py`. It writes the sentence to `/output/entry.txt`, with no trailing newline. The output is deterministic, and the program uses only the Python standard library.

## Why this line works

The setup names a familiar convenience: a password manager that keeps a long history of passwords. The turn arrives when the narrator needs the one password that matters in the moment. The ending makes the frustration sharper by pointing out that remembering passwords is the manager's whole job. That contradiction is recognizable, and the sentence gets to the punchline without extra explanation.
